SSL Certificate Errors and HTTPS Issues

SSL certificate errors disrupt secure web connections. ERR_CERT_AUTHORITY_INVALID means the certificate authority is not trusted - install the CA certificate chain. ERR_CERT_DATE_INVALID indicates an expired certificate - check with 'openssl s_client -connect host:443 | openssl x509 -noout -dates'. CN_INVALID means the certificate hostname doesn't match. For Let's Encrypt, renew with 'certbot renew'. Check certificate chain completeness - missing intermediate certificates cause chain validation failures. Test with 'openssl s_client -connect host:443 -showcerts'. Verify certificate installation on the web server (Apache: SSLCertificateFile directive; Nginx: ssl_certificate directive). Mixed content warnings occur when HTTPS pages load HTTP resources. HSTS (HTTP Strict Transport Security) can prevent access if incorrectly configured.
