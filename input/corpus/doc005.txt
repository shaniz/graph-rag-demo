High CPU Usage Investigation on Linux Servers

High CPU usage on Linux servers requires systematic investigation. Use 'top' or 'htop' to identify processes consuming CPU. 'uptime' shows load averages - a load average greater than the number of CPU cores indicates saturation. Identify specific threads with 'top -H -p <pid>'. Use 'strace -p <pid>' to see system calls made by the process. For Java applications, use 'jstack <pid>' for thread dumps. 'perf top' provides kernel-level profiling. Check for runaway cron jobs in /var/log/cron. Zombie processes appear with Z state in 'ps aux'. High system CPU (sy%) indicates kernel work - check interrupt counts with 'cat /proc/interrupts'. For web servers, check if a particular URL pattern is causing load with access log analysis. Set CPU limits with cgroups to contain runaway processes.
