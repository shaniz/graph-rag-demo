Network Connectivity Troubleshooting

When a workstation cannot connect to the network, start by checking the physical connection. Ensure the Ethernet cable is properly seated in both the NIC and the switch port. Check the link lights on both ends. If using Wi-Fi, verify the adapter is enabled and the correct SSID is selected. Run 'ipconfig /all' on Windows or 'ip addr' on Linux to verify IP configuration. If the IP is 169.254.x.x (APIPA), the machine failed to get a DHCP lease. Try 'ipconfig /release' followed by 'ipconfig /renew'. Check the DHCP server logs for errors. Ping the default gateway to test Layer 3 connectivity. If the gateway responds but internet does not work, check DNS settings with 'nslookup google.com'. Common causes include misconfigured VLAN, spanning tree issues, and incorrect subnet mask.
