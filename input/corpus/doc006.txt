Database Connection Pool Exhaustion

Database connection pool exhaustion causes application timeouts and errors. Symptoms include 'Connection timeout' or 'Unable to acquire connection from pool' errors. Check current connections: in PostgreSQL use 'SELECT count(*) FROM pg_stat_activity'. In MySQL use 'SHOW PROCESSLIST'. Compare against max_connections setting. Long-running queries block connection release - identify with 'SELECT query, now() - pg_stat_activity.query_start AS duration FROM pg_stat_activity WHERE state != idle'. Kill blocking queries with 'SELECT pg_terminate_backend(pid)'. Increase pool size in application configuration but ensure database max_connections allows it. Implement connection timeouts and checkout timeouts. Consider PgBouncer or ProxySQL for connection pooling. Monitor with pg_stat_activity and set up alerts when connections exceed 80% of max.
