Disk I/O Performance Issues

Poor disk I/O performance affects application response times. Use 'iostat -x 1' to monitor disk utilization - '%util' above 80% indicates saturation. 'iotop' shows per-process I/O consumption. High 'await' values indicate slow storage response. For HDDs, check for fragmentation and head seek times. For SSDs, monitor wear leveling with 'smartctl -a /dev/sda'. RAID degradation significantly impacts performance - check 'cat /proc/mdstat' for software RAID status. Identify files being heavily accessed with 'inotifywait -m -r /path'. Database I/O can be reduced with proper indexing. PostgreSQL's pg_statio_user_tables shows buffer hits vs disk reads. Use 'fio' for storage benchmarking. Consider LVM striping for better throughput. Check for filesystem journal issues with 'dmesg | grep -i error'.
