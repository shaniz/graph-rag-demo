Asset Delivery Slowness (Child of Frontend)

Slow delivery of images, CSS, and JavaScript files increases page load time. Parent node: Frontend Performance Issues. No child nodes — this is a leaf. Diagnose by checking the Network tab waterfall: look for large files, missing cache headers, and sequential loading of parallel-safe resources. Common causes: (1) Uncompressed assets — enable gzip or Brotli compression in Nginx (gzip on; gzip_types text/css application/javascript) or Apache (mod_deflate). (2) No CDN — serve static assets from a CDN like CloudFront or Cloudflare to reduce latency for distant users. (3) No HTTP/2 — HTTP/1.1 limits parallel connections; enable HTTP/2 on your web server. (4) Render-blocking CSS — move critical CSS inline and defer non-critical stylesheets. (5) Large images — compress with WebP format, set proper Cache-Control headers (max-age=31536000, immutable for versioned assets).
