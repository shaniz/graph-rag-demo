JavaScript Performance Problems (Child of Frontend)

JavaScript execution blocks the browser main thread and freezes the UI. Parent node: Frontend Performance Issues. No child nodes — this is a leaf. Diagnose with Chrome DevTools Performance tab: record a session and look for long tasks (>50ms). Common causes: (1) Unoptimized loops over large arrays — use pagination or Web Workers for CPU-heavy computation. (2) Excessive re-renders in React/Vue — use React.memo, shouldComponentUpdate, or computed properties. (3) Memory leaks from forgotten event listeners — use the Memory tab to take heap snapshots and compare growth. (4) Large bundle size — run 'npx webpack-bundle-analyzer' to identify oversized dependencies. Fix: code-split with dynamic import(), tree-shake unused exports, defer non-critical scripts with async/defer attributes.
