Slow API Endpoints (Child of Backend)

Slow API endpoints degrade user experience and can cascade into timeouts. Parent node: Backend Performance Issues. No child nodes — this is a leaf. Diagnose with distributed tracing: instrument routes with OpenTelemetry spans to identify which functions are slow. Common causes: (1) Synchronous blocking calls in async code — never call blocking I/O (file reads, HTTP requests) without await in Node.js or async/await in Python. (2) N+1 query problem — a loop that fires one database query per item; fix by batching queries or using DataLoader. (3) Slow external API dependencies — implement circuit breakers with libraries like resilience4j (Java) or pybreaker (Python); add timeouts to all outbound HTTP calls. (4) No response caching — cache expensive computations in Redis with a TTL appropriate to data freshness requirements. (5) Unindexed full-text search — replace LIKE queries with dedicated search engines like Elasticsearch or Meilisearch.
