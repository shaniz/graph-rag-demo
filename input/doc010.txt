Firewall and Network Security Troubleshooting

Firewall misconfigurations block legitimate traffic and create security gaps. On Linux, list iptables rules with 'iptables -L -n -v'. For UFW: 'ufw status verbose'. Windows Firewall: 'netsh advfirewall firewall show rule name=all'. Test port connectivity with 'telnet host port', 'nc -zv host port', or 'Test-NetConnection -ComputerName host -Port port'. Packet captures with Wireshark or 'tcpdump -i eth0 port 80' reveal dropped packets. Check firewall logs for DENY entries. Network security groups in cloud environments (AWS Security Groups, Azure NSG) require outbound as well as inbound rules. Stateful firewalls track connections - ensure related/established traffic is allowed. Application layer firewalls (WAF) may block based on content patterns. Trace routing issues with 'traceroute' or 'mtr' to identify where packets are dropped.
