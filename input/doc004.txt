Active Directory Authentication Problems

Active Directory authentication failures prevent users from logging into domain resources. Event ID 4625 in Security logs indicates failed logon attempts. Common causes: incorrect password, account lockout, time skew exceeding 5 minutes. Check account status with 'Get-ADUser -Identity username -Properties LockedOut, BadLogonCount'. Unlock with 'Unlock-ADAccount'. Kerberos errors (KDC_ERR_C_PRINCIPAL_UNKNOWN) indicate the account doesn't exist or is disabled. Verify DNS is pointing to Domain Controllers. Test domain connectivity with 'nltest /sc_verify:domain.com'. LDAP binding issues: check that port 389 and 636 (LDAPS) are accessible. For group policy failures, run 'gpresult /R' to see applied policies. Replication issues between DCs can be diagnosed with 'repadmin /replsummary'.
